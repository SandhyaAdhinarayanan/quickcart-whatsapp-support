# QuickCart WhatsApp Support

A MERN-based customer-support dashboard integrated with the Meta WhatsApp Cloud API.

## Current progress

### Milestone 1 — MERN Foundation

- React with Vite and TypeScript
- Node.js and Express backend
- MongoDB connection using Mongoose
- Backend health-check API
- React-to-Express API communication
- CORS and environment configuration

## Technology stack

- React
- TypeScript
- Node.js
- Express
- MongoDB
- Mongoose
